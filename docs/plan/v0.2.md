# v0.2 plan

v0.2 makes review fast enough that people keep Rowbit on, and lets one file say what each agent can see, what it can do and what needs approval. It ships as a tag, `v0.2.0`. Binaries, `rowbit demo`, agent-tool setup, the home page and the public announcement are v0.2.1; per-agent budgets are v0.3.

The behaviour is specified in [docs/spec](../spec): [rowbit.yml](../spec/policy.md) (scopes, shadow mode), the [change lifecycle](../spec/change-lifecycle.md) (scope check, `PolicyShadowed`, agent tools, web UI) and the new [rowbit-server.yml](../spec/server.md) (sign-in, notifications, MCP over HTTP, agent database users).

## Choices made in the spec

- **Shadow mode applies the change.** Following the roadmap ("records what it would have held without blocking anything"), an agent in shadow mode gets its writes applied, with preview, apply by primary key and undo, while the log records what the rules would have done. What Rowbit can't do safely (refused statements, writes outside scopes, schema changes) is still refused or held.
- **Scopes are checked by the database with `EXPLAIN`.** Running `EXPLAIN` of the canonical statement on the agent's own user makes MariaDB and MySQL check every privilege the write needs, column privileges and views included, without running it. Checked on MariaDB 11.4 and MySQL 8.4. Preview, apply and undo stay on Rowbit's user, which needs full rows and the table's triggers and foreign keys.
- **Server settings get their own file.** `rowbit.yml` stays the policy, reviewed in version control and Apache-licensed for other tools. `rowbit-server.yml` holds deployment settings, with secrets only as `${VAR}` references.
- **The password stays for one machine.** Without an identity provider, `rowbit serve` keeps v0.1's password but refuses to listen beyond loopback, so the quickstart still works without an IdP account.
- **Slack notifies; the web UI approves.** The Slack message links to the change. Approving in Slack would need Slack identities mapped to reviewers and Rowbit reachable from Slack.
- **Agents sign in over HTTP with a token each.** OAuth for MCP can come later.
- **`rowbit policy test` is in v0.2,** as on the roadmap, inside the shadow mode slice.
