    UNDER THE HOOD

    The plan. Nothing here is released yet; this page is a mock to get your opinion.

    DROP-IN PROXY

    Point your agent's connection string at Rowbit instead of the database. It speaks the database's own protocol, so nothing to migrate. Reads pass straight through.

    EXACT PREVIEW

    Each write runs once inside a transaction that is rolled back, so you see the real rows or documents it would change. Approval applies only those, pinned so nothing new sneaks in.

    RULES + HUMANS

    A small YAML file decides: auto-approve, hold for a human, or block. Review in the bundled web UI or Slack. Agents can propose and check status. Only people approve.

    UNDO ONE CHANGE

    Before-images are kept per change, so you can roll back one bad write and keep everything else. If someone edited those rows since, Rowbit shows the conflict first.
